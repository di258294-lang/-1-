개인정보 처리방침

시행일 2026년 10월 4일

HOLD는 개인정보를 수집하지 않아요. 회원가입, 로그인, 광고, 분석 도구가 없어요.

기기 안에만 저장하는 정보

게임 진행을 위해 아래 정보를 사용자의 기기 안(앱 저장소)에만 저장해요. 이 정보는 서버로 전송되지 않고, 개발자도 볼 수 없어요.

  • 오늘의 차트 결과와 시즌 계좌 금액
  • 판마다 계산한 매매 습관 점수
  • 연습 모드 기록, 안내 화면을 봤는지 여부

웹 버전은 브라우저 저장소에, 토스 앱 버전은 토스 앱의 기기 내 저장소에 저장해요. 앱을 삭제하거나 브라우저 데이터를 지우면 모두 지워져요.

웹 호스팅

웹 버전은 GitHub Pages에서 제공돼요. GitHub가 보안을 위해 접속 기록(IP 주소 등)을 처리할 수 있으며, 이는 GitHub 개인정보 처리방침을 따라요. HOLD 자체는 이 기록을 받지 않아요.

토스 앱 버전의 순위표

토스 앱 버전에서는 오늘의 차트를 마치면, 그 판에서 "그냥 들고 있는 것보다 얼마나 더 벌었는지"를 나타내는 점수 하나가 토스 게임 순위표로 보내져요. 순위표는 토스가 운영하고, 토스의 개인정보 처리방침을 따라요. HOLD 자체는 이 점수를 받거나 보관하지 않고, 순위에 따른 보상도 없어요.

알림 (Android·iOS 앱)

설정에서 "매일 알림"을 켠 경우에만 기기 안에서 하루 한 번 알림을 예약해요. 서버를 거치지 않고, 끄면 예약된 알림이 모두 지워져요.

공유 기능

결과 공유 버튼은 기기의 공유 창을 열거나 텍스트를 클립보드에 복사할 뿐이에요. 어디로 보낼지는 사용자가 직접 정해요.

게임 내용

등장하는 회사, 종목 코드, 뉴스, 가격은 모두 가상이에요. 실제 돈이 오가지 않고, 투자 권유나 자문이 아니에요.

아동의 개인정보

어떤 개인정보도 수집하지 않으므로 아동의 개인정보도 수집하지 않아요.

Privacy Policy

Effective October 4, 2026

HOLD does not collect personal data. There is no account, no login, no ads and no analytics. Game progress (daily results, the season balance, habit scores, practice records) is stored only on your device and is never sent anywhere. Deleting the app or clearing browser data removes it. The web version is hosted on GitHub Pages, which may process access logs (such as IP addresses) for security under GitHub's own privacy statement; HOLD itself never receives them. The share button only opens your device's share sheet or copies text. In the Toss app version, finishing the daily chart sends one score (how much the round beat simply holding) to the Toss game leaderboard, which Toss operates; HOLD itself never receives it and ranks carry no rewards. Daily reminders in the Android/iOS apps are scheduled on the device only when you turn them on. All companies, tickers, news and prices in the game are fictional; no real money is involved and nothing in the game is investment advice. For questions, see the support page.
