# 랜덤 인생

지금(2026년) 열네 살인 전 세계 1억 3,750만 명 중 한 명으로 깨어나 그 사람의 일생을 살아보는 게임이에요. 어느 나라, 어떤 집에 태어날지는 나라별 실제 14세 인구 비율대로 정해지고, 학교, 일, 결혼, 출산, 병, 죽음이 그 나라의 실제 통계를 따라 흘러가요. 중요한 순간마다 플레이어가 고르고, 선택지에 없는 행동은 직접 적으면 Claude가 그 나라의 현실에 맞춰 이야기를 만들어요.

이 폴더는 같은 저장소의 HOLD 게임과 아무 관련이 없어요. HOLD의 파일은 건드리지 않아요.

## 플레이

- `build/random-life.html` 하나로 돌아가요. Claude 기능(직접 행동, 이어지는 이야기, 성향 측정, 회고록)은 claude.ai 아티팩트로 열었을 때만 켜지고, 그 밖에서는 기본 선택지만으로 끝까지 플레이할 수 있어요.
- 1년은 1배속에서 약 50초예요. 0.5×/1×/2×/4× 속도와 일시정지가 있어요. 결정 장면이 뜨면 시간이 멈춰요.
- **집중**(공부·일·사람·건강·놀기·균형)과 **씀씀이**(절약·보통·여유)로 매달 능력치와 돈이 달라져요.
- **직접 행동**: 언제든 하고 싶은 일을 적으면 Claude가 성공 확률을 정하고 결과를 만들어요. 결과는 이야기로 끝나지 않고 직업, 공부, 창업, 이사·이민, 연애·결혼, 습관, 돈, 능력치에 실제로 반영돼요. 시간이 걸리는 일은 '이어지는 이야기'가 되어 몇 달 뒤 Claude가 다음 장면과 선택지를 새로 만들어요.
- **결정** 탭에서 지난 결정 직전으로 돌아가 다르게 골라볼 수 있어요. 인생 로드맵을 시험해 보는 샌드박스로 쓰기 좋아요.
- **내 조건으로 살아보기**: 나라, 성별, 나이, 집안 형편, 학력, 직업, 결혼, 자녀, 저축을 정해서 시작해요.
- 끝나면 Claude가 그 인생의 결정 기록(상황, 고를 수 있던 선택지, 실제로 고른 것, 직접 쓴 행동, 시간 배분)을 읽고 **인생 성향**을 직접 측정해요. 미리 정한 축이나 유형표 없이 기록에서 드러나는 성향을 찾아요. 여러 번 살고 나면 처음 화면에서 인생들을 종합해 플레이어 본인의 성향을 측정받을 수 있어요.

## 데이터

| 무엇 | 출처 |
|---|---|
| 나라별 14세 인구(출생 추첨), 2026~2100년 연령별 사망률, 연령별 출산율, 기대수명, 5세 미만 사망률 | UN 세계인구전망 2024 (중위 추계) |
| 나라·나이·성별 사망원인 (40여 개 원인) | WHO 세계보건추정 2023 |
| 소득 분포(10분위), 빈곤율, 학교 취학·졸업, 학력, 실업, 비공식 고용, 아동노동, 조혼, 흡연, 음주, 의료비, 인터넷, 금리, 물가, 난민, 분쟁 사망 등 80여 개 지표 | 세계은행 세계개발지표 (최근값) |
| 성별 직업 분포(ISCO-08), 직업별 월평균 임금 | ILOSTAT |
| 학제·시험 이름, 병역, 종교 비율, 평균 초혼 연령, 은퇴 연령, 지명·이름 | 각국 제도와 공개 통계를 반올림해 정리 (`src/curated.js`) |

182개국, 전 세계 14세의 99.95%를 다뤄요. 통계가 없는 지표는 같은 지역·소득 수준 나라들의 중앙값으로 채우고, 고소득국에 없는 조사 지표(조혼, 아동노동 등)는 0에 가까운 값으로 채웠어요. 대만, 북한, 베네수엘라처럼 세계은행 GDP가 없는 곳은 각국 통계청·IMF 추정치를 반올림해 넣었어요(`tools/build_data.py`의 `MANUAL_MONEY`).

돈은 2026년 물가 기준 현지 화폐로 보여줘요. 최근 1인당 GDP(현지 화폐)를 최근 물가상승률로 2026년까지 늘리고, 그 비율로 구매력 기준 달러를 바꿔요.

## 검증

`tools/sim.mjs`가 화면 없이 인생 수천 개를 무작위 선택으로 살아보고 원 통계와 비교해요.

```bash
node life/tools/sim.mjs 2000            # 전체, 첫 선택지로 조금 기우는 선택
node life/tools/sim.mjs 2000 all random # 완전 무작위 선택
node life/tools/sim.mjs 500 KOR         # 한 나라만
```

해외로 이주하지 않은 사람의 평균 사망 연령이 UN 생명표가 말하는 14세의 기대 수명과 1년 안팎으로 맞도록 위험 요인(흡연, 음주, 소득, 직업, 건강 상태, 진단받은 병)을 나라별 평균이 1이 되게 정규화하고, 남는 차이를 `E.CALIB`로 맞췄어요.

## 다시 만들기

```bash
python3 life/tools/fetch_raw.py <원본 폴더>                  # UN·WHO·세계은행·ILO 원본 내려받기 (약 330MB)
python3 life/tools/build_data.py <원본 폴더> life/src/data.js  # 게임용 데이터로 가공
node life/build.mjs                                           # build/random-life.html 하나로 묶기
```

## 파일

- `src/engine.js`: 출생 추첨, 가족 배경, 월 단위 시간, 돈, 능력치, 사망과 사망원인, 되돌리기
- `src/events.js`: 결정 장면(진학, 시험, 전공, 병역, 취업, 승진, 연애, 중매, 결혼, 출산, 질병, 이사, 이민, 투자, 부모 부양, 분쟁, 은퇴)과 Claude 결과 적용
- `src/flavor.js`: 그 나라 사정(전기, 물, 인터넷, 종교 명절, 기후, 일)에 맞춘 일상
- `src/claude.js`: Claude에게 보내는 요청(직접 행동, 다음 장면, 성향 측정, 회고록)
- `src/ui.js`, `src/styles.css`, `src/index.html`: 화면
