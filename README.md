# HOLD

누르고 있는 동안만 들고 있어요. 매일 하나의 차트, 40초 타이밍 게임이자 **매매 습관 코치**예요.

모든 회사, 코인, 뉴스, 가격은 지어낸 것이고 실제 돈은 오가지 않아요. 투자 권유나 조언이 아니에요.

## 게임

- **조작**: 화면 아래 패드를 누르고 있으면 사고, 떼면 팔아요. 계속 누르기 힘들면 설정에서 "탭으로 사고팔기"를 켤 수 있어요.
- **목표**: 그냥 계속 들고 있는 것보다 더 버는 것. 사고팔 때마다 수수료가 붙어서 "언제 참을지"가 실력이에요.
- **뉴스**: 판마다 뉴스가 떠요. 1.6초 뒤 가격이 반응해요. **공식 발표**는 항상 사실이고 **소문**은 반만 맞아요. 뉴스 띠의 "좋은 소식 / 나쁜 소식"은 헤드라인이 말하는 방향일 뿐, 실제로 그렇게 될지는 몰라요.
- **첫 판은 튜토리얼**: 처음 시작하면 20초짜리 연습 판에서 코치가 조작을 알려줘요. 기록에는 남지 않아요.
- **오늘의 차트**: 한국 시간 0시마다 바뀌고 모두 같은 차트, 하루 한 번. 요일마다 상품이 달라요(일·월·목 주식, 화 채권, 수 금, 금 레버리지 2배, 토 코인).
- **연습 모드**: 무제한, 매번 새 차트. 판을 할수록 상품이 열려요(주식 → 채권 → 금 → 코인 → 레버리지).
- **장기 모드 (5분 = 1년)**: 250거래일을 5분에. 한 달짜리 판에선 작게 보이던 효과(레버리지의 변동성 끌림, 채권 이자)가 크게 드러나요.
- **상품 5가지**: 주식, 채권(금리 뉴스에 반대로), 금(위기 뉴스에 상승), 코인(가장 크게 출렁임, 소문이 대부분), 레버리지 2배(하루 한 번 2배로 재조정).

## 결과와 코칭

- **결과 화면**: 위에는 세 가지만. 성적(나 vs 시장), 가장 중요한 한 가지(미션 결과나 습관 한 줄), 다음에 할 일. 나머지(수수료, 이자, 뉴스 다시 보기, 운 검정 분포, 상품 교훈)는 "자세히 보기" 안에 있어요.
- **운일까 실력일까**: 내가 들고 있던 구간들의 길이는 그대로 두고 같은 차트에서 위치만 1,000번 무작위로 옮겨 봐요. 매매 횟수와 수수료가 정확히 같고 다른 건 타이밍뿐이에요. "아무렇게나 누른 가상 플레이어 중 이만큼 이상 낸 경우는 약 N%예요"처럼 빈도로만 말하고, 실력이라고 단정하지 않아요.
- **매매 습관 진단**: 손실 버티기(처분 효과), 너무 일찍 팔기, 자주 사고팔기, 오른 뒤 따라 사기, 소문 따라가기. 모두 "그 차트에서 아무렇게나 눌렀어도 이 정도는 나온다"보다 확실히 더할 때만 습관이라고 불러요. 매매가 있었던 판이 5판 쌓이면 성향 유형이 나오고, 최근 10판만 반영해서 습관을 고치면 바뀌어요.
- **미션**: 가장 두드러진 습관에 맞춘 과제 하나("손실은 기준선 안에서 정리하기" 등). 안 누르거나 마구 눌러서는 통과할 수 없고, 최근 판정 3판 중 2판을 해내면 완료예요. 2주 뒤에 유지되는지 한 번 더 확인해요.
- **상황별 교훈**: 그 판에서 실제로 일어난 일에 맞춘 짧은 교훈 10가지. 한 판에 하나, 같은 교훈은 한 번만.
- **습관 추이**: 습관마다 낮음/보통/높음과 "처음 5판 → 최근 5판" 변화를 보여줘요. 우연한 차이는 "비슷해요"로 표시해요.

## 다시 오게 만드는 것

- **연속 기록과 휴장일**: 7일 연속마다 휴장일이 하나 생겨요(최대 2개). 하루 이틀 놓쳐도 연속 기록을 지켜줘요. 홈의 요일 줄에서 이번 주를 한눈에 봐요.
- **시즌 계좌**: 오늘의 차트 결과가 한 달 동안 가상 1,000만 원 계좌에 복리로 쌓여요. 달이 끝나면 시장, 예금과 비교한 결산 카드와 메달이 나와요.
- **주간 챌린지**: 매주 모두에게 같은 규칙 하나("매매 3번 이하로 시장 이기기" 등). 그 주 오늘의 차트 중 3번 해내면 완료.
- **기록 화면**: 달력, 이번 주, 시즌, 누적 실력 검정(최근 판들의 운 검정 순위 평균), 지난 시즌 메달. 달력에서 지난 날을 누르면 그날 차트를 다시 할 수 있어요(기록에는 안 남아요).
- **친구 도전 링크**: 판이 끝나면 같은 차트로 겨루는 링크를 보낼 수 있어요. 서버 없이 링크 하나에 차트와 내 수익률이 담기고, 고친 링크는 열리지 않아요. 오늘의 차트 도전장은 내가 오늘 차트를 먼저 해야 열려요.
- 보상은 습관 개선에만 줘요. 매매 횟수 배지, 축하 폭죽, 무작위 보상, 결제는 없어요.

```
HOLD #12 · 코인 (가상 게임)  +12.4%
그냥 들고 있었으면 -3.1%
운 비교 · 무작위 배치 1,000번 중 상위 12%
■■□□■■□□■■
```

## 실행

```bash
npm install
npm run dev          # http://localhost:5173
npm test             # 단위 테스트 (vitest)
npm run build        # 타입체크 + 웹 빌드 (dist/)
npm run test:e2e     # 브라우저 스모크 테스트 (Playwright)

npm run font         # 한글 문구를 바꾼 뒤: 쓰는 글자만 담은 글꼴 다시 만들기 (pip install fonttools brotli)
npm run font:check   # CI: 문구에 쓴 한글이 글꼴에 다 있는지

python3 scripts/build-single.py dist-single/hold.html   # 글꼴까지 담은 HTML 파일 하나

npm run og           # 링크 미리보기 이미지 public/og.png (1200×630)
npm run store-shots  # 빌드 후 스토어 스크린샷·그래픽을 store/에 (커밋 안 함)
npm run card-preview # 결과 이미지 카드 샘플을 store/card/에
```

## 앱 (Android / iOS / 앱인토스)

- [Capacitor](https://capacitorjs.com)로 같은 웹 빌드를 네이티브 앱으로 감싸요(`android/`, `ios/`). `npm run cap:sync` 후 `npx cap open android`.
- 앱인토스: `npm run build:toss` → `.ait` 파일, `npm run deploy:toss`.
- 푸시할 때마다 GitHub Actions가 테스트 후 웹 버전을 GitHub Pages에 올리고, 테스트용 안드로이드 APK를 만들어요.

## 출시 이미지

- **링크 미리보기**: `index.html`의 `og:*`, `twitter:card`가 `public/og.png`를 가리켜요. 주소는 `.env`의 `VITE_SHARE_URL`(끝에 `/`)에서 빌드할 때 채워져요.
- **결과 이미지 카드**: `src/ui/card.ts`가 1080×1080, 1080×1920(스토리) PNG를 캔버스로 그려요. 스포일러 없는 ⭕/❌ 판정은 `src/core/card.ts`.
- **스토어 이미지**: `scripts/store-shots.mjs`가 실제 빌드를 가짜 시계로 일주일 플레이해서 찍어요. 크기와 명령은 [docs/RELEASE.md](docs/RELEASE.md#출시-이미지-체크리스트).
