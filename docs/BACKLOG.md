# 개선 백로그 (v0.5)

5개 진단 팀(QA, 게임 디자인·리텐션, 퀀트 검수, 아키텍처·성능·테스트, 앱인토스 출시 준비)이 코드 전체를 감사한 결과를 합친 목록이에요. 각 항목에 담당 팀과 상태를 적어요.

상태: ⏳ 진행 중 · ✅ 완료 · 📋 다음 단계

## 1단계: 기반 수정 (5개 구현 팀 병렬) ✅

엔진(퀀트 모델팀), 습관(행동재무팀), 저장소(데이터팀), 플레이(게임플레이팀), 플랫폼팀이 모두 끝내고 합쳤어요. 단위 테스트 152개, 브라우저 자동 점검 56개 중 54개 통과(나머지 2개는 저장소가 깨진 저장 파일을 복구하게 바뀌어 더 이상 해당 없음).

## 2단계: 리텐션 기능 ✅

성장팀(요일 줄·시즌 결산·기록 화면·지난 차트·누적 실력 검정), 고객경험팀(튜토리얼·사운드·설정·쉬운 말), 코칭팀(미션·상황별 교훈·결과 화면 재구성·습관 추이), 소셜팀(친구 도전 링크·주간 챌린지)이 끝내고 합쳤어요. 아래 표의 6번(친구 도전), 9번(주간 챌린지)까지 모두 반영됐고, 10번(학습 배지)은 미션 완료 기록으로 대신했어요.

게임 디자인 팀의 조사(Wordle, NYT 게임, 듀오링고, 하이브리드 캐주얼 벤치마크, 행동재무 교육 연구)에 근거해요. 모든 보상은 노력으로만 얻고, 무작위 보상과 결제는 없어요.

| 순위 | 기능 | 왜 |
|---|---|---|
| 1 | 사운드 (체결음, 뉴스 알림음) + 끄기 설정 | 손맛, 앱인토스 체크리스트 |
| 2 | 연속 기록 보호권 "휴장일" + 요일 줄 | 듀오링고 스트릭 보호로 이탈 21% 감소 |
| 3 | 습관 개선 미션과 추적 ("손실 버티기 62 → 31") | 진단을 코치로. 적극적 피드백이 처분 효과를 줄인다는 연구 |
| 4 | 시즌 결산 카드 + 시장 대비 성적 + 메달 | 한 달의 목표와 기록 |
| 5 | 튜토리얼 판 + 결과 화면 단계적 공개 | 첫 판이 되돌릴 수 없는 오늘의 차트인 문제 |
| 6 | 친구 도전 링크 (같은 차트로 대결) | 서버 없이 소셜 |
| 7 | 기록 화면 + 누적 실력 검정 (최근 10판 평균 백분위) | 장기적인 성장을 숫자로 |
| 8 | 지난 오늘의 차트 다시 하기 | 밀린 날 채우기, 복기 |
| 9 | 주간 제약 챌린지 ("매매 3번 이하로 시장 이기기") | 주 단위 재방문, 실력 천장 높이기 |
| 10 | 학습 배지 (매매 횟수가 아니라 습관 개선에만) | 거래량을 부추기는 배지는 역효과라는 연구 |

## 준법 📋

`docs/COMPLIANCE.md` 참고. 앱 문구(고지, 미션형 팁, 글꼴 라이선스, 처리방침)는 반영했고, 계정 명의(법정대리인), 출시 순서(구글 플레이 → 앱인토스), 운영자 이름·연락처 기입은 사람이 해야 해요.

## 3단계: 통합 감사와 수정 ✅

품질본부 감사 5팀(QA, 통계, 사용자 리서치, 아키텍처, 출시 전략)이 합친 앱을 다시 검사했고, 수정 4팀이 고쳤어요.

| 팀 | 고친 것 |
|---|---|
| A 통계 정직성 | 미션 통과 규칙(최근 4판 중 3판), 손절 미션은 반응 시간으로, 운으로 끝나는 미션 차단, 탐색 중 유형, 누적 실력 검정의 반복 확인 보정(z ≥ 2.9), 습관 추이(깨끗한 구간 + 순열 검정), 주간 챌린지는 보유 시간만큼의 시장과 비교, 등급 기준을 상품 변동성에 맞춤, 운 문구를 실제 확률로 |
| B 데이터·플랫폼 | 토스 저장소가 늦을 때 기록이 지워지던 문제(P0), 판 도중 1초마다의 전체 저장 → 작은 칸, 저장 한 번으로 묶기, 읽기 캐시, 저장 불가 시 오늘의 차트 막기, 기록 규칙 한 곳으로, 웹 뒤로가기 보호, 앱 안 처리방침, 토스 스와이프 뒤로가기 막기, 실제 흐름 e2e 테스트 |
| C 화면·재방문·공유 | 튜토리얼에서 톡톡 치는 사람 잡기와 "이번엔 진짜예요", 입구 하나로, 친구 도전장 기억해 두기, 운 검정을 맨 위·공유에서 빼기, 스포일러 없는 ⭕/❌ 공유, 홈·결과 화면 덜어내기, 대비·글자 크기·화면 낭독기 |
| D 출시 자료 | 카톡 미리보기 이미지(og.png), 결과 이미지 카드(1:1, 9:16), 스토어 스크린샷 자동 생성, 출시 이미지 체크리스트 |
