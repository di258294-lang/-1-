# 개선 백로그 (v0.5)

5개 진단 팀(QA, 게임 디자인·리텐션, 퀀트 검수, 아키텍처·성능·테스트, 앱인토스 출시 준비)이 코드 전체를 감사한 결과를 합친 목록이에요. 각 항목에 담당 팀과 상태를 적어요.

상태: ⏳ 진행 중 · ✅ 완료 · 📋 다음 단계

## 1단계: 기반 수정 (5개 구현 팀 병렬)

| # | 문제 | 근거 | 담당 |
|---|---|---|---|
| 1 | 나가기 창을 띄운 채 앱을 전환하면 게임이 뒤에서 다시 흘러 오늘의 차트로 기록됨 | QA·아키텍처, 브라우저 재현 | 플레이 팀 |
| 2 | 탭을 숨기면 손을 뗐는데도 계속 보유 상태 | QA, 브라우저 재현 | 플레이 팀 |

## 2단계: 리텐션 기능 📋

게임 디자인 팀의 조사(Wordle, NYT 게임, 듀오링고, 하이브리드 캐주얼 벤치마크, 행동재무 교육 연구)에 근거해요. 모든 보상은 노력으로만 얻고, 무작위 보상과 결제는 없어요.

| 순위 | 기능 | 왜 |
|---|---|---|
| 1 | 사운드 (체결음, 뉴스 알림음) + 끄기 설정 | 손맛, 앱인토스 체크리스트 |
| 2 | 연속 기록 보호권 "휴장일" + 요일 줄 | 듀오링고 스트릭 보호로 이탈 21% 감소 |
| 3 | 습관 개선 미션과 추적 ("손실 버티기 62 → 31") | 진단을 코치로. 적극적 피드백이 처분 효과를 줄인다는 연구 |
| 4 | 시즌 결산 카드 + 시장 대비 성적 + 메달 | 한 달의 목표와 기록 |
| 5 | 튜토리얼 판 + 결과 화면 단계적 공개 | 첫 판이 되돌릴 수 없는 오늘의 차트인 문제 |
| 6 | 친구 도전 링크 (같은 차트로 대결) | 서버 없이 소셜 |
| 7 | 기록 화면 + 누적 실력 검정 (최근 10판 평균 백분위) | 장기적인 성장을 숫자로 |
| 8 | 지난 오늘의 차트 다시 하기 | 밀린 날 채우기, 복기 |
| 9 | 주간 제약 챌린지 ("매매 3번 이하로 시장 이기기") | 주 단위 재방문, 실력 천장 높이기 |
| 10 | 학습 배지 (매매 횟수가 아니라 습관 개선에만) | 거래량을 부추기는 배지는 역효과라는 연구 |
