# 기획 메모

## 왜 이 게임인가

**틈새.** 차트 게임은 이미 있어요 (Chart Game, US Stock Chart Game 등). 전부 "오를까 내릴까"를 한 번씩 고르는 퀴즈형이고, 화면은 증권사 HTS를 줄여놓은 모양이에요. 반면 위에서 잘 되는 건 두 부류예요.

1. **매일 한 번, 모두 같은 문제, 결과 공유** (Wordle, Connections 계열). 하루 1회 제한이 오히려 재방문을 만들고, 공유 텍스트가 광고가 돼요.
2. **한 손, 한 동작, 짧은 세션** (하이퍼캐주얼). 다만 2026년엔 순수 하이퍼캐주얼보다 여기에 진행/라이브옵스를 얹은 하이브리드 캐주얼이 매출을 가져가요.

HOLD는 이 둘을 합쳐요. 조작은 "누르고 있기" 하나지만, 수수료 때문에 참는 판단이 생기고, 뉴스(공시/지라시) 때문에 읽는 판단이 생겨요. 차트 게임 중에 **실시간 손맛**과 **매일 공유** 둘 다 있는 건 아직 없어요.

**왜 한국에서 먼저.** 주식 앱 사용자가 많고 "존버", "물렸다", "지라시" 같은 말이 일상어예요. 빨강=상승, 파랑=하락 관례도 그대로 써요. 해외판은 색 관례만 뒤집으면 돼요 (초록=상승).

## 법적으로 조심한 부분

- **실제 돈이 오가지 않아요.** 가상 1,000만 원, 현금화 없음, 결제로 게임머니 구매 없음. 사행성 게임물로 볼 여지를 원천 차단.
- **확률형 아이템 없음.** (한국은 2024년부터 확률 공개 의무. 넣을 계획이 생기면 확률 표기부터.)
- **회사, 종목 코드, 뉴스 전부 가상.** 실존 상장사 이름이나 로고를 쓰지 않고, 화면에 "모두 가상"이라고 적어요. 실제 시세 데이터도 쓰지 않아요 (데이터 제공사 약관 이슈 회피). 가격은 시드 난수로 생성.
- **투자 권유로 오해받지 않게.** 특정 종목 추천, 매매 신호, "수익 보장" 같은 문구 금지. 앱스토어 설명에도 "게임"임을 명시.
- **개인정보 수집 없음.** 기록은 기기 안(localStorage)에만.
- **폰트는 Pretendard (SIL OFL 1.1).** 앱 번들 포함 가능.
