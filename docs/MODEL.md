# 시장 모델과 판정 알고리즘

게임의 숫자가 "그럴듯한 랜덤"이 아니라 실제 시장의 통계적 성질을 따르도록 만든 설계와, 그걸 검증한 방법이에요. 코드는 `src/core/market.ts`, `habits.ts`, `luck.ts`, `lessons.ts`이고, 검증은 `src/core/model.test.ts`, `luck.test.ts`에 테스트로 들어 있어요.

## 1. 가격 모델

한 틱(0.1초)마다 로그 수익률을 이렇게 만들어요.

```
r_t = (μ_regime − σ²/2)·dt  +  √h_t · z_t  +  J_t
```

| 구성 | 모델 | 왜 |
|---|---|---|
| 추세 `μ_regime` | 상승/하락/횡보 3상태 **마르코프 국면 전환** (Hamilton, 1989). 하루에 국면이 유지될 확률 0.9, 평균 10거래일 | 시장은 추세가 있는 구간과 없는 구간이 번갈아 와요 |
| 잡음 분산 `h_t` | **GARCH(1,1)**: `h_t = ω + α·ε²_{t−1} + β·h_{t−1}`, α=0.1, β=0.89 | 큰 움직임 뒤에 큰 움직임이 몰려 와요 (변동성 군집) |
| 충격 `z_t` | 분산 1로 맞춘 **Student-t** 분포 (자유도 3~5) | 실제 수익률은 정규분포보다 급등락이 훨씬 잦아요 (두꺼운 꼬리) |
| 뉴스 `J_t` | **포아송 도착** 점프. 크기는 상품별 평균 주변 로그정규 분포 | 뉴스는 아무 때나 오고, 가격은 한 번에 갭으로 반응해요 |

### 시간 척도

짧은 판(40초)은 **한 달(20거래일)**, 장기 모드(5분)는 **1년(250거래일)**이에요. 변동성, 추세, 이자 모두 연 단위 값으로 정의하고 `dt`로 나눠 쓰기 때문에 두 모드가 같은 시장을 다른 길이로 보여줘요.

### 분산 예산

상품마다 실제 자산군의 **연 변동성**을 목표로 정하고, 그 분산을 뉴스 점프, 국면 추세, 틱 잡음이 나눠 가져요.

```
σ²_잡음 = (σ²_목표 − λ·252·J²·E[m²]) / (1 + (4/3)·k²·ℓ)
```

(λ: 하루 뉴스 수, J: 점프 크기, k: 추세 기울기 배수 5, ℓ: 평균 국면 길이 10/252년)

추세 기울기를 잡음 변동성의 5배로 둔 건 **게임을 위한 선택**이에요. 실제 장기 수익률 추세는 이보다 훨씬 약해서, 그대로 두면 몇 초 동안의 움직임이 전부 잡음이 돼요. 대신 총 분산을 목표에 맞추기 때문에 1년을 하면 실제 자산만큼만 흔들려요.

### 상품별 설정

| 상품 | 목표 연 변동성 | 비고 |
|---|---|---|
| 주식 | 35% | 개별 종목 수준. 뉴스 하루 0.12개, 점프 4% |
| 채권 | 금리 변동성 90bp | **가격을 직접 만들지 않고 금리를 시뮬레이션**해요 (아래) |
| 금 | 15% | 위기 뉴스에 상승 |
| 코인 | 75% | 꼬리가 가장 두꺼움(자유도 3), 뉴스의 75%가 지라시 |
| 레버리지 2배 | 지수 20% → 상품 약 40% | **하루 한 번** 2배로 재조정 (아래) |

### 채권

금리를 **바시첵(Vasicek) 모형** `dy = κ(θ − y)dt + σ_y·dW + 점프`로 움직이고, 가격은 실제 채권 공식으로 계산해요.

```
dP/P = y·dt − D·dy + ½·C·dy²
```

`y·dt`는 들고 있는 동안 받는 이자, `D`는 듀레이션(10년물 8.5, 3년물 2.8), `C`는 볼록성이에요. 그래서 "금리 0.15%p 상승 → 10년물 약 −1.3%"가 공식대로 나와요.

### 레버리지 2배

실제 레버리지 ETF처럼 **하루에 한 번** 노출을 순자산의 2배로 다시 맞추고, 하루 안에서는 마지막 재조정 이후 지수 움직임의 2배로 움직여요. 그 결과 아래 식이 성립해요.

```
1 + P ≈ (1 + U)² · exp(−Σ r_d²)
```

결과 화면은 단순 2배(2U)와의 차이를 **추세 효과** `(1+U)² − (1+2U)`와 **변동성 끌림** `(1+U)²·(exp(−Σr²) − 1)`로 나눠서 보여줘요.

## 3. 운일까 실력일까

같은 차트에서 **플레이어와 비슷한 스타일의 무작위 트레이더 1,000명**(장기 모드는 400명)을 돌려서, 내 수익률이 그중 몇 등인지 보여줘요.

- 무작위 트레이더는 2상태 마르코프 체인이에요. 플레이어와 **기대 매매 횟수와 보유 시간 비율이 같도록** 전환 확률을 맞춰요.
- 수수료와 현금 이자까지 똑같이 계산해서 공정하게 비교해요(라운드 엔진과 소수점 10자리까지 일치하는지 테스트해요).
- 순열 검정과 같은 생각이에요. "상위 3%"는 **운만으로 이 정도가 나올 확률이 약 3%**라는 뜻이에요.

**모델 점검 결과**: 같은 방법으로 스크립트 플레이어를 돌렸어요(상품별 150판 평균 백분위).

| 전략 | 주식 | 채권 | 금 | 코인 | 레버리지 |
|---|---|---|---|---|---|
| 공시만 보고 움직이기 | 90% | 93% | 88% | 88% | 92% |
| 지라시 따라가기 | 45% | 50% | 51% | 44% | 49% |
| 단순 차트 추세 따라가기 | 51% | 52% | 51% | 51% | 48% |

확인된 정보를 읽는 실력은 보상받고, 소문과 과거 가격 패턴만으로는 이길 수 없어요. 실제 시장의 효율성과 같은 성질이에요.

## 4. 매매 습관 측정

- **처분 효과** (Shefrin & Statman 1985, Odean 1998): 수익 중인 틱과 손실 중인 틱에서 **각각 팔 확률(위험률)**을 구해 비교해요. 판수가 적을 때 극단값이 나오지 않게, 전체 매도율을 사전분포로 써서 **경험적 베이즈 수축**을 해요(가상 노출 30틱). 수익 상태와 손실 상태를 각각 2초 이상 겪은 판에서만 비교해요.
- **모든 가격 기준은 그 차트의 변동성 단위**예요. 변동성은 뉴스 점프에 휘둘리지 않도록 중앙절대편차(MAD × 1.4826)로 재요. 그래서 "−2% 손실"이 채권과 코인에서 다르게 취급돼요.
- **추격 매수**는 2초 안에 2시그마 넘게 오른 직후의 매수예요.
- **잦은 매매**는 40초 기준 매매 횟수로 환산해서, 짧은 판과 장기 모드를 같은 기준으로 봐요.
- **판별 기준 검증**: 7가지 스크립트 스타일을 300개 차트에 돌려서 각 스타일이 맞는 유형으로 분류되는지 확인했어요(손실 버티기 56/60, 추격 56/57, 연타 60/60, 규칙형→기계형 44/47).
