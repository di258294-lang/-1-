# 출시 전략 (v0.6)

성장·출시팀이 2026-10-04에 웹 검색으로 조사한 결과예요(구글 플레이 한국, 앱인토스 개발자 문서, 커뮤니티 규칙). 출처 URL은 각 항목에 있어요. 법률 자문이 아니고, 순위·리텐션 수치는 추정이 섞여 있어요.

## 바뀐 사실 (COMPLIANCE.md보다 최신)

- **토스 미니앱은 2026-06-08부터 만 14세 이상에게 노출**돼요. 게임은 등급분류(또는 자체등급)에 따라요. 워크스페이스 생성과 QR 테스트는 여전히 만 19세 이상이고, 미성년자는 법정대리인 워크스페이스에 **확약서를 쓰고 초대**받을 수 있어요. ([공지](https://techchat-apps-in-toss.toss.im/t/topic/4033), [미성년자 안내](https://developers-apps-in-toss.toss.im/guide/operation/console-minor.md)) 문서마다 표현이 달라서 채널톡으로 확인 필요.
- **토스 앱 이름에 "HOLD" 단독은 안 돼요.** 영어 이름은 15자 이하, 흔한 단어 하나는 불가. → 한글 **"홀드"**, 영어 **"HOLD Timing"**.
- **토스 포인트 프로모션은 사업자등록 + 5만 원 충전 필요.** 점수·승패·순위에 따른 보상과 무작위 보상은 금지. **게임 리더보드는 개인도 무료.** 토스 푸시는 기능성만(리텐션·마케팅 금지).
- ~~웹 빌드에 `og:image`가 없어서 카톡 링크에 미리보기 카드가 안 떠요.~~ → `public/og.png`(1200×630)와 `og:*` 태그를 넣었어요 (`npm run og`).

**빈자리**: "모두 같은 오늘의 차트 + 손가락 하나 실시간 타이밍 + 매매 습관 진단"을 함께 하는 앱이 없어요. 국내 경쟁작은 증권사 HTS 흉내(평점 낮음)거나 타이쿤·스토리 게임이에요. "모의투자" 검색은 실제 시세 금융 앱이 차지해서 의도가 달라요.

## 구글 플레이 스토어 문구

- **카테고리**: 게임 › 시뮬레이션 (국내 주식 게임이 모두 여기 있어서 "비슷한 앱"에 같이 노출). 교육은 아동 앱 카테고리라 피해요.
- **제목 후보** (30자 이하)
  1. `HOLD 홀드: 40초 주식 차트 타이밍 게임` ← 추천
  2. `홀드: 매일 하나의 주식 차트 게임`
  3. `HOLD: 40초 매매 습관 게임`
- 제목에는 "모의투자·재테크·투자·코인"을 넣지 않아요(검색 의도가 다르고, 투자 교육으로 오해될 수 있음). "주식"은 장르 설명이라 괜찮아요.
- **짧은 설명**: `누르면 사고 떼면 파는 40초 주식 타이밍 게임. 매일 같은 가상 차트로 내 매매 습관을 확인해요.`

### 전체 설명 (붙여 넣기용)

```
실제 돈이 오가지 않는 가상 시장 타이밍 게임이에요. 회사·코인·뉴스는 모두 지어낸 것이고, 투자 권유가 아니에요.

누르고 있는 동안만 들고 있어요.
손가락을 대면 사고, 떼면 팔아요. 조작은 그게 전부예요.
한 판은 40초. 언제 참고 언제 내릴지가 이 게임의 전부예요.

■ 매일 0시, 모두에게 같은 차트 하나
한국 시간 0시마다 오늘의 차트가 열려요. 모든 플레이어가 같은 차트로, 하루 한 번만 해요.
오늘의 차트 결과는 한 달 동안 가상 1,000만 원 시즌 계좌에 이어져요.

■ 40초면 내 매매 습관이 보여요
판이 끝나면 내가 실제로 어떻게 움직였는지 숫자로 보여줘요.
5판을 하면 성향 유형이 나와요. 존버형, 새가슴형, 자주 사고파는 형, 따라 사는 형, 소문 따라가는 형, 냉정한 기계형.
진단은 "이렇게 하세요"가 아니라 "이렇게 행동했어요"만 알려주고, 다음 판에 해 볼 미션을 하나씩 드려요.

■ 운일까, 실력일까
내가 들고 있던 구간을 같은 차트의 아무 때로 1,000번 옮겨 보고 비교해요.
아무렇게나 누른 것 중 나만큼 이상 낸 비율을 그대로 보여주고, 한 판만으로 실력이라고 단정하지 않아요.

■ 공식 발표는 믿고, 소문은 의심하고
판마다 뉴스가 뜨고 잠시 뒤 가격이 움직여요.
공식 발표는 늘 맞지만 소문은 반이 틀려요. 따라갈지 말지는 내가 정해요.

■ 주식, 채권, 금, 코인, 레버리지 2배
요일마다 오늘의 차트 상품이 바뀌어요. 모두 가상 상품이에요.
채권은 금리 뉴스에 반대로, 금은 위기 뉴스에 오르고, 코인은 크게 출렁여요.
레버리지 2배는 정말 2배일까요? 직접 해 보면 알게 돼요.
가격은 통계 모델로 만든 가상 시장에서 움직여요. 실제 시세나 실제 종목은 쓰지 않아요.

■ 수수료도 진짜처럼
사고팔 때마다 수수료가 빠져요. 마구 누르면 손해예요. 쉬는 동안엔 현금에 작은 이자가 붙어요.

■ 더 하고 싶을 때
· 연습 모드: 무제한, 매번 새 차트
· 장기 모드: 5분에 1년. 250거래일을 압축해서 예금과 비교
· 주간 챌린지: "매매 3번 이하로 시장 이기기" 같은 한 주짜리 과제
· 친구 도전: 같은 차트로 겨루는 도전장 링크

회원가입 없이 바로 할 수 있고, 기록은 내 기기에만 저장돼요.

등장하는 회사, 뉴스, 가격은 모두 가상이에요.
실제 돈은 오가지 않고, 게임 속 결과는 실제 투자 성과나 투자 조언이 아니에요.
```

### 앱인토스 등록

- 검색어: 타이밍 게임, 차트 게임, 40초, 매일 게임, 습관 진단. "주식 게임"은 채널톡 사전 확인 뒤에.

## 스크린샷 구성 (9:16, 6장)

모든 장면 하단에 `모든 회사·가격·뉴스는 가상이에요`. `npm run store-shots`가 실제 빌드로 찍어서 `store/play/`(1080×1920)와 `store/appstore/`(1320×2868)에 만들어요. 6번은 캡션이 한 줄에 안 들어가서 "친구에겐 도전장으로 / 같은 차트로 겨뤄요. 결과는 10칸으로 공유해요."로 줄였어요.

1. 패드를 누른 손가락과 오르는 선 — **누르는 동안만 들고 있어요** / 떼면 팔아요. 조작은 이게 전부.
2. 홈의 오늘의 차트와 요일 줄 — **매일 0시, 모두에게 같은 차트 하나** / 하루 한 번, 40초.
3. 뉴스 띠: 공식 발표와 소문 — **공식 발표는 믿고, 소문은 의심하고** / 소문은 반이 틀려요.
4. 결과 화면과 운 비교 — **운일까 실력일까** / 아무 때나 누른 1,000판과 비교.
5. 습관 유형과 미션 — **40초면 매매 습관이 보여요** / 고칠 미션도 하나씩.
6. 공유와 친구 도전장 — **결과는 10칸으로, 친구에겐 도전장으로**.

## 제품 우선순위 (도박 요소 없이)

1. **스포일러 없는 공유 + 이미지 카드(1:1, 9:16) + og:image** — 0원 성장의 유일한 엔진.
2. **진짜 순위표: 토스 게임 리더보드 먼저** — 개인 무료. 순위에 보상을 걸면 안 돼요.
3. **선택형 하루 알림** — 사용자가 고른 시간, 하루 한 번, 쉽게 끄기. 토스는 기능성 메시지 심사 확인 필요.
4. **좋은 순간 뒤 인앱 리뷰 요청** — 세 번째 오늘의 차트를 잘 끝낸 뒤 등. 진 판 뒤, 보상 걸기 금지.
5. **영어·초록 상승 웹판 (2단계)** — 해외 매일 주식 게임은 모두 퀴즈형이라 실시간 자리가 비어 있어요.
