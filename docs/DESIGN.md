# 디자인 원칙

목표는 두 가지: **핀테크 앱처럼 보일 것**, **AI가 만든 티가 안 날 것**.

## 'AI 티' 목록과 여기서 한 선택

디자이너 커뮤니티(스레드, 브런치, 해외 블로그)에서 반복해서 지목되는 패턴을 모아 하나씩 피했어요. 주의할 점은 "AI 티 빼줘"라고 하면 AI가 꺼내는 **2차 기본값**도 이미 티가 난다는 것.

| 흔한 패턴 | 여기서는 |
|---|---|
| 보라~파랑 그라데이션, 그라데이션 글자 | 그라데이션 없음. 색은 잉크(검정)와 돈의 색(빨강/파랑)뿐 |
| 2차 기본값: 크림 배경 + 테라코타, 검정 + 형광 초록 | 차가운 회백색 캔버스 + 흰 면. 브랜드 포인트 색 자체를 두지 않음 |
| Inter 폰트 | Pretendard. 숫자는 전부 `tabular-nums` |
| 모든 카드에 회색 1px 테두리 + 그림자 | 테두리/그림자 없음. 캔버스와 면의 명도 차이로만 구분 |
| 카드 한쪽에 두꺼운 색 띠 | 없음 |
| 제목 위 알약 배지, 색 점 | 없음. 날짜/회차는 평범한 회색 텍스트 |
| 이모지 아이콘, 작은 색 박스 속 아이콘 | UI에 이모지 없음 (공유 텍스트만 예외, 관례라서). 아이콘은 닫기 하나, 직접 그린 SVG |
| 대문자 모노 라벨, 01 / 02 / 03 번호 | 없음. 라벨은 한국어 문장형 |
| 가운데 정렬 히어로 + 기능 카드 3개 | 왼쪽 정렬, 화면당 결정 하나 |
| 모든 요소 fade-up, hover scale | 움직임은 누를 때 피드백과 시트 등장만. `prefers-reduced-motion` 존중 |
| 글래스모피즘 | 없음 |
| 줄표(—) 많은 문장, "잠재력을 깨워보세요" 류 카피 | 해요체, 짧게. 줄표 안 씀 |

## 핀테크 느낌을 만드는 것

- **숫자가 주인공.** 평가금액은 화면에서 가장 큰 글자. 콤마, 원, 부호, 고정폭 숫자.
- **한국 증권 관례.** 빨강 = 상승/이익, 파랑 = 하락/손실. 등락률 부호는 일반 하이픈 (`-7.03%`).
- **실제 매매 앱의 디테일.** 오른쪽 가격 태그, 진입가 점선, 보유 구간 음영, "이번 매매 +0.93%".
- **한 화면에 한 가지.** 홈은 "시작하기", 플레이는 "누르기", 결과는 "공유하기".

## 토큰

`src/styles.css`의 `:root`. 라이트/다크 둘 다 정의. 색을 새로 추가할 때는 토큰부터.

| 토큰 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| `--ink` | #111418 | #eef0f3 | 본문, 주 버튼, 누른 패드 |
| `--canvas` | #f2f3f5 | #0c0e11 | 배경 |
| `--surface` | #ffffff | #16191e | 면 |
| `--well` | #e9ebee | #1f2329 | 보조 버튼, 누르기 전 패드 |
| `--up` | #e0263a | #ff4a5c | 상승, 이익 |
| `--down` | #1a62d6 | #4d8dff | 하락, 손실 |
